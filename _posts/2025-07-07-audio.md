[Kira](https://github.com/tesselode/kira) is a backend-agnostic library to create expressive audio for games. It provides tweens for smoothly adjusting properties of sounds, a flexible mixer for applying effects to audio, a clock system for precisely timing audio events, and spatial audio support.

### Threading Model

Kira uses a **multi-threaded architecture** with clear separation of concerns:

1. **Main Thread**: Your game logic runs here and sends commands to the audio system
2. **Audio Thread**: A dedicated high-priority thread handles all audio processing and mixing
3. **Command Queue**: Thread-safe communication between main and audio threads

The `AudioManager` acts as the bridge - when you call `manager.play()`, it doesn't immediately play the sound. Instead, it queues a command that gets processed on the audio thread during the next audio callback.

### Backend Abstraction

Kira doesn't handle the low-level audio hardware directly. Instead, it sits on top of audio backends like:
- **CPAL** (Cross-Platform Audio Library) for most platforms
- **Web Audio API** for WASM/browser environments
- Custom backends can be implemented

This means Kira focuses on the high-level audio logic while delegating the platform-specific audio I/O to proven libraries.

## Key Systems

### 1. Resource Management
- **Static Sounds**: Loaded entirely into memory, good for short effects
- **Streaming Sounds**: Read from disk in chunks, perfect for long music tracks
- **Automatic Cleanup**: Finished sounds are automatically removed from memory

### 2. Mixer Architecture
The mixer is built around **tracks** - think of them as mixing board channels:
```
Main Track
├── Music Track (with reverb effect)
├── SFX Track (with compressor)
└── Voice Track (with EQ filter)
```

Each track can have:
- Volume/pan controls
- Audio effects (filters, reverb, etc.)
- Sub-tracks for further organization

### 3. Parameter System
Instead of immediately changing audio properties, Kira uses **tweens** (smooth interpolations):
- Want to fade out music? Set volume to 0.0 with a 2-second tween
- Need to speed up a sound? Tween the playback rate from 1.0 to 2.0
- This prevents audio pops and clicks that happen with instant changes

### 4. Clock System
Games need precise timing, so Kira provides **clocks** that:
- Tick at specified rates (e.g., 120 BPM for music)
- Allow scheduling sounds to play at exact times
- Can be started, stopped, and synchronized
- Handle tempo changes smoothly

## Audio Processing Pipeline

When you play a sound, here's what happens:

1. **Command Queuing**: `manager.play()` queues a "play sound" command
2. **Audio Callback**: The audio thread processes queued commands
3. **Sound Instance Creation**: Creates a new sound instance with its parameters
4. **Mixing**: Each frame, all active sounds are mixed together
5. **Effects Processing**: Track effects are applied to the mixed audio
6. **Output**: Final audio is sent to the audio backend

This happens **thousands of times per second** (typically 44,100 Hz sample rate), so efficiency is crucial.

## Memory and Performance

### Smart Memory Management
- **Reference Counting**: Multiple sound instances can share the same audio data
- **Automatic Cleanup**: Finished sounds are removed without manual intervention
- **Streaming**: Large files don't consume excessive memory

### Performance Optimizations
- **Lock-Free Communication**: Uses atomic operations and ring buffers for thread communication
- **Efficient Mixing**: Optimized audio mixing routines
- **Minimal Allocations**: Avoids memory allocations during audio playback

## Real-Time Safety

Audio threads are **real-time critical** - they can't wait for memory allocation or disk I/O. Kira handles this by:
- Pre-allocating buffers and data structures
- Using lock-free data structures for thread communication
- Deferring heavy operations to background threads

The "backend-agnostic" design means your game audio code stays the same whether you're targeting Windows, Linux, Mac, or even web browsers - Kira handles the platform differences for you.
